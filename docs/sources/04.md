IMPLEMENTATION ROADMAP & TEST PLAN
Version 0.1 — Ordered proposed milestones.


M0 — INITIALIZE
Set up Python package with src layout, uv or standard packaging, pytest/pytest-asyncio, Ruff, CI, README and license decision. Start Git repository. Agree Python minimum version and package name.


M1 — CORE CONTRACTS (FIRST CODE)
Implement Task, TaskResult, statuses, AgentAdapter, ExecutionContext. Implement Runtime.execute with FakeAgent. Tests for success/failure/timeout/cancel and cleanup. Acceptance: no network, keys or external CLI required.


M2 — ACP ADAPTER
Use ACP Python SDK rather than implementing wire protocol from scratch. Select one known compatible agent. End-to-end simple read-only task; record logs and normalized results. Acceptance: core API unchanged.


M3 — DELEGATE SKILLS INTEGRATION
Pin tested upstream version. Build CLI relay adapter, structured result parser, process supervisor, workspace scoping and diffs. Acceptance: output normalized exactly like ACP. Document differences in capabilities.


M4 — DELEGATION ENGINE
Generate explicit bounded task briefs, select adapter, validate prerequisites, await result, review diffs/artifacts, require approval when appropriate. Initially one task at a time.


M5 — MCP AND POLICY
Separate tool registry and MCP adapters. Add permission policy and audit events for tool actions; test deny/allow, secret redaction and refusal propagation.


M6 — ROBUSTNESS / PARALLELISM
Git worktree isolation, cancellation propagation, concurrency limits, independent retries, recovery and conflict detection. Add stress/fault injection tests.


M7 — DOCUMENTATION / PUBLIC API
Examples, API reference, packaging/release strategy, compatibility matrix, changelog, integration guide. SemVer once API stabilizes.


TEST MATRIX
Unit: contract validation; state machine transition guards; error mapping; event order; timeout/cancel; fake adapter; policy denial.
Integration: ACP handshake/session/prompt; relay subprocess exit, stderr, malformed result and signal handling; Git diff against approved workspace.
Security: path traversal, prompt injection, command argument escaping, secret leakage, accidental commit/push, concurrent filesystem changes.
Performance: bounded tasks and backpressure; later parallel load testing.


FIRST DEVELOPMENT TICKET
Create src/agent_runtime/core/models.py + protocols.py + runtime.py. Write deterministic tests with FakeAgent for success, failure, cancellation and timeout. No real SDK adapter in this ticket.


COMPLETION DEFINITION
All tests pass; ruff passes; structured result independent of adapter; no external service needed. Update decision log with changed choices.
