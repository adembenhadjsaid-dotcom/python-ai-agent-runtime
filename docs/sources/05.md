RISKS, OPEN QUESTIONS & REFERENCES
Version 0.1 — 27 October 2026


OPEN ARCHITECTURAL DECISIONS
• Python minimum version and asynchronous framework policy.
• License, package name and public compatibility guarantees.
• Tasks versus durable runs versus sessions semantics.
• Event schema and persistence (in-memory for MVP vs database).
• Agent discovery and capability negotiation semantics.
• Approval gates: interactive caller callbacks vs persistent approvals.
• ACP subprocess and cancellation handling across agents.
• Delegate Skills upstream version and real commands/API.
• Whether an existing coding agent may recursively delegate tasks.
• MCP transport implementation and least-privilege permission boundaries.
• Isolation: subprocess, container, Git worktree, network allowlist.
• Credential management and telemetry policy.


RISKS + MITIGATIONS
Vendor integration drift → pin tested versions and adapter contract tests.
Privilege escalation/tool abuse → explicit authorization and workspace scopes; never trust upstream default flags.
Concurrent writes → one writer MVP; isolated worktrees later.
Duplicate work on retry → idempotency decisions and never retry blindly after uncertain side effects.
Prompt injection from repo/files → treat context as untrusted; apply tool boundaries.
Opaque outcomes → normalized result + raw diagnostic metadata, trace IDs.
Overarchitecture → implement vertical slice before generalized registries/plugins.

GLOSSARY
Harness: host/runtime environment used by coding agents.
Adapter: boundary mapping external transport/tool semantics to our internal contract.
ACP: Agent Client Protocol, agent-client interoperability.
MCP: Model Context Protocol, tool/context integration; distinct from ACP.
Delegation: assignment of a bounded task to another agent with validation/review.
Runtime: lifecycle and policy enforcement around execution.


MAINTENANCE RULE
Date each architectural change; mark decisions ACCEPTED/PROPOSED/OPEN; link code PRs to modified contracts; never silently conflate proposal with approved decision.
