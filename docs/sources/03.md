ACP + DELEGATE SKILLS — INTEGRATION DESIGN
Version 0.1 — Research/verification required for exact upstream APIs before implementation.


UPSTREAM RESOURCES
ACP overview: https://zed.dev/acp
ACP Python SDK: https://github.com/agentclientprotocol/python-sdk
ACP SDK quickstart: https://agentclientprotocol.github.io/python-sdk/quickstart/
Delegate Skills: https://github.com/amElnagdy/delegate-skills


DIFFERENT RESPONSIBILITIES
ACP is an agent-client communication protocol, with transport/session/prompt/event concepts. It does not by itself define our higher-level team workflow.
Delegate Skills, attributed to Ahmed El Nagdy, is a delegation-oriented set of skills and relays for delegating coding work to external agents, collecting outcomes and reviewing work. Exact compatibility/version must be checked at implementation time.


COMPOSITION PROPOSAL
User goal → DelegationService constructs Task + constraints → Runtime.execute → Adapter (ACP preferred if supported, CLI relay fallback) → TaskResult → review/approval gate.
Do not assume Delegate Skills itself speaks ACP. Do not make ACP equal to an orchestrator or assume ACP is a model/provider API.


ACP ADAPTER TASKS
1. Verify SDK version, agent compatibility and process startup handshake.
2. Map Task to ACP session initialization and prompt.
3. Translate streaming session updates and tool requests into our events.
4. Surface approval/permission requests to our policy/approval boundary.
5. Map terminal status, cancellation, failures and resource teardown.
6. Integration-test with one documented compatible agent.


DELEGATE RELAY ADAPTER TASKS
1. Verify actual CLI commands and relay inputs/outputs against the pinned upstream revision.
2. Construct least-privilege delegation brief and scoped workspace.
3. Spawn and supervise process with deadline/cancel handling.
4. Parse structured results when available; treat plain text as untrusted.
5. Extract touched files/diff metadata safely; independently verify Git diff.
6. Send result to review gate; no implicit acceptance, commit or push.


CAPABILITY DISCOVERY
Adapters advertise available operations: read/write workspace, supports_streaming, supports_cancel, supports_tools, supports_sessions. These are proposed categories rather than claims that all providers implement them.


INTEGRATION RISKS
ACP/agent version skew; inconsistent tool permissions; CLI subprocess cleanup; untrusted output; arbitrary side effects; collisions when multiple agents write to same directory; nested delegation; prompt injection in repository content.


EXIT CONDITIONS
One agent can execute a safe test task through ACP adapter; a separate relay can execute a test task through CLI adapter; both produce normalized TaskResult and pass analogous contract tests.
