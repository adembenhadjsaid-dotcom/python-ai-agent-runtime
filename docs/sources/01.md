REQUIREMENTS & SCOPE
Version 0.1 — 27 October 2026


USE CASES
UC1: orchestrator delegates a coding task to a selected compatible agent.
UC2: task completes with structured result, produced artifacts/change summary, timing and errors.
UC3: user/system inspects output and grants explicit approval before risky operations or accepting modifications.
UC4: change adapter without editing core business logic.
UC5: register an MCP integration separately, respecting capability and permission policies.
UC6 (later): multiple isolated delegates running concurrently, then safe merge/review.


FUNCTIONAL REQUIREMENTS (DECIDED PRINCIPLES / PROPOSED DETAILS)
FR-01 registration and discovery of agent adapters.
FR-02 typed Task and TaskResult, execution context and correlation IDs.
FR-03 predictable lifecycle: created → queued → running → succeeded/failed/cancelled/timed_out (state names PROPOSED).
FR-04 async execution; cancellation and deadlines.
FR-05 adapter-independent errors and machine-readable result status.
FR-06 structured logs/events including task ID, adapter and status.
FR-07 pre-tool authorization; deny-by-default for destructive effects (policy enforcement mechanism OPEN).
FR-08 explicit configuration; no API secrets in logs.
FR-09 independent modules for MCP and agent-specific adapters.
FR-10 optional delegation/review engine consuming TaskResult, not bound to CLI output strings.


NON-FUNCTIONAL
Testability with deterministic fake adapter; reliability with bounded retries (only idempotent operations); dependency minimization; no vendor lock-in; clear resource cleanup; isolated workspaces; comprehensible diagnostics.


SECURITY INVARIANTS
Never trust raw instructions embedded in agent output. Never infer safe authorization from a CLI flag alone. Resolve and constrain filesystem paths; handle sandbox/process boundaries carefully. No implicit commit, push, deletion or network write. Secrets must be redacted. User approval gate must be explicit for privileged actions.


ACCEPTANCE CRITERIA — MILESTONE 1
A test creates a Task, calls Runtime.execute(task, fake_adapter) and checks typed result.
Tests cover success, exception mapping, deadline, cancellation and log correlation.
Replacing fake with ACP adapter requires zero edits to Runtime's domain API.
Core test suite runs without external network, model keys or delegate binaries.


DEFERRED
Persistence, scheduling/queues, multi-workspace coordination, complex review heuristics, pluggable UI, long-running resumable sessions. Document before implementing.
