ARCHITECTURE & INTERFACE CONTRACTS
Version 0.1 — Proposed detailed design; principles agreed, signatures subject to tests.


LAYERED DESIGN
Application / Orchestrator
  → Domain Runtime (task lifecycle, scheduling, cancellation, event emission)
  → AgentAdapter interface (protocol-neutral)
  → ACP / CLI Relay / future harness adapters
Cross-cutting: permissions, configuration, logging, telemetry, workspace isolation.
Delegation Engine composes runtime tasks and review decisions; it should not embed transport primitives.


COMPONENT RESPONSIBILITIES
core/models.py — immutable Task, TaskResult, AgentCapabilities, ErrorKind and ExecutionContext contracts.
core/protocols.py — AgentAdapter and optional event-stream capability.
core/runtime.py — state transitions, timeout/cancel orchestration, consistent error normalization.
adapters/acp.py — ACP client transport and session/prompt mapping; no domain policy logic.
adapters/delegate_cli.py — process launch/termination, stderr/stdout parsing, result normalization.
delegation/service.py — agent selection, delegation brief, review result, policy gate.
security/policy.py (later) — authorization decisions and scoped workspace/capability grants.
observability/events.py (later) — structured events, correlation IDs and optional exporters.


INITIAL CONTRACT SKETCH (NOT FINAL PYTHON API)
class AgentAdapter(Protocol):
    async def execute(self, task: Task, context: ExecutionContext) -> TaskResult: ...


Task: id, instructions, workspace, constraints, requested_capabilities, deadline.
ExecutionContext: cancellation, permissions, trace_id, callbacks/events.
TaskResult: status, summary, artifacts, changed_files, normalized_error, raw_metadata.


RULES
Core never imports ACP SDK or delegate CLI package.
Adapters translate external status/errors to domain types.
Transport/session lifecycle is owned by the adapter; runtime owns task lifecycle.
No raw untrusted model output is executable policy.
Streaming may be an optional protocol to avoid forcing all adapters to stream.
Cancel and timeout need an explicit process/session cleanup strategy.
Retries need idempotency and duplicate-action safeguards.

DESIGN VALIDATION
Build one vertical slice before generalizing. Treat serial delegation as default for MVP; introduce parallel worktrees only after write-conflict and review semantics have tests.
