# M1 Core Contracts and Minimal Runtime Implementation Plan

> Execution: use superpowers:executing-plans inline, followed by a fresh review.
> The user authorized building M1 from the supplied documents; no new design approval
> is required for this bounded implementation. Keep all defaults provisional.

**Goal:** Execute a single typed task through a transport-neutral adapter, offline.
**Architecture:** Immutable domain contracts and a small asyncio runtime. Adapters own
resource cleanup; the runtime owns state, deadlines, cancellation and safe error mapping.
**Tech Stack:** Python >=3.11, asyncio/dataclasses/typing/logging; pytest, pytest-asyncio, Ruff.
**Spec:** Project documents 00–05 in ../../sources/; scope/choices in ../../decisions.md.

## Global Constraints

- M1 only; no real SDK adapter, CLI, tools, delegation, queues, persistence or retries.
- No runtime dependencies, secrets in runtime logs, or destructive operations.
- ACP and Delegate Skills remain independent implementations behind AgentAdapter.

## Review Focus

- Simultaneous cancel/completion and repeated caller cancellation: cleanup still awaited.
- Expired/invalid deadlines and timeouts: no unintended execution.
- Malformed or mismatched adapter results: fail closed, never report false success.
- Reused runtime/adapters: no cancellation/state leakage between executions.
- Exception messages containing credentials: no disclosure through runtime logs/results.
